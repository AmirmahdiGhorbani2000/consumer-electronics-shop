# consumer-electronics-shop
فروشگاه اینترنتی لوازم الکترونیکی مصرفی، پلتفرم فول‌استکی برای خرید آنلاین موبایل و لپ‌تاپ است که با React، Node.js و MongoDB ساخته شده. امکانات اصلی شامل احراز هویت با JWT، سبد خرید، پرداخت امن با زرین‌پال و پنل مدیریت محصولات است. رابط کاربری واکنش‌گرا و راست‌چین، همراه با سئو و PWA، تجربه‌ای بهینه در همه دستگاه‌ها ارائه می‌دهد.
